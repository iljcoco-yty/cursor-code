# cursor-code

## Superpowers 插件

本项目已集成 [Superpowers](https://github.com/obra/superpowers) 插件，提供 TDD、调试、协作等开发技能。

### 初始化（首次克隆后）

```bash
git submodule update --init --recursive
```

### 在 Cursor 中使用

- 插件位于 `.cursor/plugins/superpowers/`
- 也可在 Cursor Agent 聊天中输入 `/add-plugin superpowers` 从 Marketplace 安装
